# サッと食レポ

外食のサッとしたメモから、食べログ用の口コミ文を組み立てる投稿補助アプリです。

- 単一HTML・依存ゼロ・オフライン動作（開いた端末のブラウザ内 localStorage に保存）
- 文章生成は端末内のキーワード辞書＋組み立てロジックのみ。**生成AIは使いません**
- 食べログには公式APIがなくスクレイピングは規約違反のため、**自動投稿はしません**。生成した文章をコピーして、最後はご自身で貼り付けてください

## 使い方

`index.html` をブラウザで開くだけです（ビルド不要）。GitHub Pages で公開すると、スマホ・PCの両方から同じURLで使えます。

スマホでは、ブラウザでページを開いて「ホーム画面に追加」しておくと、アプリのように一発で起動できます。
